GLASSWITCH FOR MAC

Support

A browser change, clearly explained.

Updated September 8, 2026

Get started

Requires macOS 26 or later. Open Glasswitch, click the browser icon in the menu bar, and choose an installed compatible browser. If macOS asks for confirmation, approve the change. The checkmark identifies the current default browser.

Set it up once

Open Settings from the menu panel. Click a browser icon in the browser row to choose your default directly; macOS may ask for confirmation. Choose Launch at Login, English or Chinese or the system language, and Light, Dark, or Follow System appearance. Glasswitch changes the macOS default browser; it does not intercept links, choose a browser per website, or switch browser profiles.

A browser is missing

The list depends on compatible apps installed on your Mac. A browser must register support for both HTTP and HTTPS links. After installing a browser, open Glasswitch Settings and choose Refresh. If it is still absent, include the browser name and version in a support report.

A change did not take effect

Allow any macOS confirmation to finish, then check the selected row again. If the change fails or is cancelled, Glasswitch shows the reported state. Refresh in Settings if the displayed browser seems out of date. The Mac App Store edition uses the macOS system flow and does not offer Quick mode.

Report a problem

Search existing issues before filing a new one. English and Chinese are welcome. Include your macOS version, Glasswitch version/build, browser name and version, steps to reproduce, and expected versus actual behavior. GitHub Issues are public and require an account to submit. Remove sensitive content from screenshots.

Purchases and refunds

Apple handles App Store purchases. For a billing question or refund request, use Apple’s purchase support. Eligibility and handling depend on Apple’s policies and your region. Do not post receipts or payment details in a public issue.
