GLASSWITCH FOR MAC

How to change your default browser on Mac

Your default browser is the app macOS normally uses when you open a web link from another app. You can change it in System Settings. If you switch often, Glasswitch brings the system default browser choice to the menu bar on macOS 26 or later.

Change it in System Settings

On macOS Ventura 13 or later, open the Apple menu, choose System Settings, then Desktop & Dock. Find Default web browser and select the installed browser you want. You do not need to buy an app to make this change.

On older macOS versions, the setting is in System Preferences under General. Glasswitch itself requires macOS 26 or later.

Switch between Safari and Chrome

Install Chrome first if you want to select it. Choose Google Chrome in the Default web browser menu to use it for ordinary web links opened from other apps. To switch back, choose Safari in the same menu.

Changing the default does not move your existing tabs, bookmarks, passwords, or browser profiles. Keep using each browser’s own features for those tasks.

Switch from the Mac menu bar with Glasswitch

Glasswitch is a menu bar utility for people who regularly change their system default browser. Its icon shows the current default; opening the panel lists compatible browsers installed on your Mac.

Choose a browser, complete any confirmation requested by macOS, and check the selected row. The App Store edition uses the macOS system flow for HTTP and HTTPS. It does not promise to remove system confirmation prompts.

Glasswitch is being prepared for the Mac App Store. The homepage will provide the store link when the app is publicly available.

Changing the default versus choosing a browser for each link

Choose a system default switcher when you want ordinary web links to open in your currently selected browser. A link picker instead lets you choose when opening a link; a routing tool can use rules for different sites or apps.

Glasswitch changes the system default. It does not intercept links, route websites, or select browser profiles. Apps with their own browser settings or built-in web views may behave differently from the system default.

If a browser is missing or the change seems incomplete

Make sure the browser is installed. Glasswitch lists browsers registered for both HTTP and HTTPS. Use Refresh in Glasswitch Settings after installation, and check whether a macOS confirmation is still waiting.

Check the Default web browser setting again. If only one app keeps opening links differently, inspect that app’s own link-opening settings. For a Glasswitch problem, use the support page and include your macOS, app, and browser versions.
