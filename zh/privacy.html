GLASSWITCH FOR MAC

隐私政策

应用、网站与支持

更新于 2026 年 9 月 8 日

应用本地处理

Glasswitch 在 Mac 本地读取当前默认浏览器及已安装兼容浏览器的基本信息。语言、外观及其他应用偏好保存在本地。应用无需账户，不含广告、跟踪或第三方分析 SDK，也不读取浏览历史、网页内容、Cookie、密码或书签。

本网站

公开营销网站托管于 GitHub Pages。我们未添加分析或广告跟踪器。静态站会在浏览器本地存储中保存语言选择；清除此网站的数据即可移除该偏好。GitHub 可能按其隐私声明处理 IP 地址等连接信息及技术请求日志。应用本地处理，不代表网站托管服务不处理数据。

自愿提交的支持资料

选择“反馈”会在浏览器中打开公开 GitHub 问题跟踪页。提交问题需要 GitHub 账户。你选择提交的问题内容、附件及公开账户资料可被维护者和其他访客看到。请仅提供说明问题所需的信息，不要提交密码、账户凭据、私人网址、购买凭证或其他敏感资料。GitHub 按其政策处理账户与内容托管。

Apple 服务

App Store 购买、下载和更新由 Apple 处理。Apple 隐私政策适用于这些服务及你选择向 Apple 提供的信息。这些服务与 Glasswitch 对浏览器及偏好的本地处理相互独立。
