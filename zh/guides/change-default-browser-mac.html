GLASSWITCH FOR MAC

Mac 如何更改默认浏览器

从其他应用打开普通网页链接时，macOS 通常会使用系统默认浏览器。你可以在系统设置中更改它。如果需要经常切换，Glasswitch 可在 macOS 26 或更高版本的菜单栏中提供这个选择。

在系统设置中更改

在 macOS Ventura 13 或更高版本中，打开苹果菜单，进入“系统设置”，选择“桌面与程序坞”，找到“默认网页浏览器”，再选中想使用的已安装浏览器。完成这项设置不需要购买应用。

更早版本的 macOS 可在“系统偏好设置”的“通用”中找到该选项。Glasswitch 应用本身需要 macOS 26 或更高版本。

在 Safari 和 Chrome 之间切换

如果想把 Chrome 设为默认浏览器，先完成安装，再在“默认网页浏览器”列表中选择 Google Chrome。想恢复 Safari 时，在同一个列表中选回 Safari 即可。

更改默认浏览器不会迁移已打开的标签页、书签、密码或浏览器用户配置；这些仍需通过浏览器自身的功能管理。

使用 Glasswitch 从菜单栏切换

Glasswitch 适合需要经常更改系统默认浏览器的用户。菜单栏图标显示当前默认浏览器，打开面板后可以选择 Mac 上已安装的兼容浏览器。

选中浏览器后，完成 macOS 可能要求的确认，再检查列表中的勾选状态。App Store 版本通过 macOS 系统流程处理 HTTP 和 HTTPS，不承诺跳过系统确认框。

Glasswitch 正在准备登陆 Mac App Store。正式公开后，主页会提供商店入口。

更改系统默认与逐个链接选择有什么区别

如果希望普通网页链接使用当前选中的浏览器，可以选择系统默认浏览器切换工具。链接选择器则在打开链接时让你选择，规则分流工具还可以按网站或来源应用分配浏览器。

Glasswitch 更改的是系统默认设置，不拦截链接、不按网站分流，也不选择浏览器用户配置。带有内置网页视图或独立浏览器设置的应用，行为可能与系统默认不同。

浏览器没有出现，或更改似乎未生效

先确认浏览器已经安装。Glasswitch 列出注册支持 HTTP 与 HTTPS 的浏览器；安装后可以在 Glasswitch 设置中刷新，并检查是否有尚未完成的 macOS 确认框。

再次查看系统的“默认网页浏览器”选项。如果只有某个应用仍使用其他浏览器，请检查该应用的链接打开设置。反馈 Glasswitch 问题时，请通过支持页提供 macOS、应用和浏览器版本。
