快速上手

Glasswitch 需要 macOS 26 或更高版本。

  1. 从 Mac App Store 下载并打开 Glasswitch。
  2. 点击菜单栏中的浏览器图标，勾选标记表示当前默认浏览器。
  3. 选择想使用的浏览器。
  4. 如果 macOS 请你确认，批准更改即可。
小提示：在设置中打开登录时自动启动，Glasswitch 就会一直待在菜单栏。

设置与偏好

在菜单面板中选择设置，打开设置窗口。

  • 默认浏览器：查看当前默认浏览器，并从浏览器图标中选择新的默认。
  • 登录时自动启动：登录 Mac 后自动运行 Glasswitch。
  • 语言：简体中文、English，或跟随 macOS 语言。
  • 外观：浅色、深色或跟随系统。
  • 刷新：重新读取当前默认浏览器和已安装浏览器列表。
  • 最近活动：查看本次运行期间的切换记录。

找不到某个浏览器

Glasswitch 会列出同时注册支持 HTTP 和 HTTPS 链接的应用。

  1. 确认浏览器已完整安装，并从“应用程序”文件夹打开过一次。
  2. 在 Glasswitch 设置中选择刷新。
  3. 仍然没有出现？请反馈问题，并附上浏览器名称和版本。

更改没有生效

  1. 检查是否有尚未处理的 macOS 确认框，它可能被其他窗口挡住了。
  2. 打开菜单面板，查看勾选标记在哪个浏览器上。
  3. 如果显示的浏览器似乎没有更新，在设置中选择刷新。

如果只有某个应用仍用其他浏览器打开链接，请检查该应用自己的设置。有些应用有独立的浏览器选项，或使用内置网页视图。

Mac App Store 版使用 macOS 标准流程，切换时系统可能会请你确认。

Glasswitch 不做什么

Glasswitch 修改的是 macOS 系统默认浏览器。它不会：

  • 拦截链接，或每次询问用哪个浏览器打开
  • 按网站或来源应用分配浏览器
  • 切换浏览器用户配置
  • 在浏览器之间迁移标签页、书签、密码或浏览记录

退出或卸载

  1. 退出：打开菜单面板，点击电源按钮。
  2. 卸载：先在设置中关闭登录时自动启动，退出 Glasswitch，再把它从“应用程序”文件夹移到废纸篓。

默认浏览器会保持为你最后一次选择的浏览器。

购买与退款

Mac App Store 的购买均由 Apple 处理。账单问题或退款申请，请使用 Apple 购买支持。是否符合条件取决于 Apple 政策和所在地区。

请不要在公开的 GitHub Issue 中发布收据或付款信息。
