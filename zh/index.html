为什么选择 Glasswitch

不必再绕进系统设置。

在 Mac 上更改默认浏览器，通常要在系统设置里层层寻找。Glasswitch 把它放到你随时看得到的地方。

系统设置

5 步
  1. 打开苹果菜单
  2. 选择“系统设置”
  3. 进入“桌面与程序坞”
  4. 找到“默认网页浏览器”
  5. 选择浏览器

Glasswitch

2 步
  1. 点击菜单栏中的浏览器图标
  2. 选择浏览器

macOS 可能会请你确认这次更改。这是系统在保护你的选择，Glasswitch 会尊重它。

使用方式

一分钟内完成设置。

  1. 安装并打开

    从 Mac App Store 获取 Glasswitch。图标会出现在菜单栏，显示当前默认浏览器。

  2. 选择浏览器

    点击图标，选择 Mac 上任意已安装的兼容浏览器。

  3. 按需确认

    如果 macOS 请你确认，批准即可。勾选标记会移到新的默认浏览器上。

说明：Glasswitch 修改的是 macOS 系统默认浏览器。它不拦截链接，不按网站分配浏览器，也不切换浏览器用户配置。

常见问题

你可能想知道。

没有找到答案？请访问使用与支持。

为什么 macOS 会请我确认更改？

macOS 会保护默认浏览器设置，应用更改它时系统可能要求确认。Mac App Store 版 Glasswitch 使用 Apple 标准的系统流程，出现确认框是正常的。

能让特定链接用指定浏览器打开吗？

不能。Glasswitch 修改的是系统默认浏览器，不会按网站或来源应用分配链接，也不会选择浏览器用户配置。

支持哪些浏览器？

Mac 上任何同时注册支持 HTTP 和 HTTPS 链接的浏览器，包括 Safari、Google Chrome、Firefox、Microsoft Edge、Arc 和 Dia 等。刚安装了新浏览器？在设置中点“刷新”即可。
